
# meta-bananapi

Renesas RZV2N Yocto/OpenEmbedded Layer, support bananapi ai2n board.

## prepare

Obtain the RZ/V2N AI SDK Source code from [Renesas](https://renesas-rz.github.io/rzv_ai_sdk/6.00/howto_build_aisdk_v2n.html)

Extract the source code and clone meta-bananapi

    $ mkdir -p ${WORK}/src_setup
    $ cd ${WORK}/src_setup
    $ unzip <Path to the file>/RTK0EF0189F*_linux-src.zip -d ${WORK}/src_setup

    $ mkdir ${WORK}/ai2n_yocto
    $ cd ${WORK}/ai2n_yocto
    $ tar zxvf ${WORK}/src_setup/rzv2n_ai-sdk_yocto_recipe_*.tar.gz
    $ cd ${WORK}/ai2n_yocto
    $ git clone -b bpi-ai2n https://github.com/BPI-SINOVOIP/meta-bananapi.git

Get the docker image for Source code building

    $ docker pull sinovoip/bpi-build-v2h-yocto:ubuntu20.04
    $ docker run --privileged --pid=host -it -v ${WORK}:${WORK} -v /etc/localtime:/etc/localtime -v /dev:/dev -v /proc:/proc -v /tmp:/tmp sinovoip/bpi-build-v2h-yocto:ubuntu20.04 /bin/bash

## build

    $ cd ai2n_yocto

Update the patch file before building

    --- a/patch/0000-AI_SDK-settings.patch
    +++ b/patch/0000-AI_SDK-settings.patch
    @@ -7,14 +7,14 @@ index 6ee1347..aa32196 100644
      # this doesn't mean anything to you.
      CONF_VERSION = "2"
     +
    -+BB_NO_NETWORK = "1"
    ++BB_NO_NETWORK = "0"
     +BB_GENERATE_MIRROR_TARBALLS = "1"
     +BB_GENERATE_SHALLOW_TARBALLS = "1"
     +BB_GIT_SHALLOW = "1"
     +BB_GIT_SHALLOW_DEPTH = "1"
     +
     +IMAGE_ROOTFS_EXTRA_SPACE = "6291456"
    -+WKS_FILE = "rz-image-bootpart-esd.wks"
    ++WKS_FILE = "bananapi-rz-image-esd.wks"
     +
     +SDKIMAGE_FEATURES:append = " staticdev-pkgs dev-pkgs dbg-pkgs"
     +

Initialize a yocto build

    $ TEMPLATECONF=${PWD}/meta-bananapi/meta-renesas-bsp/conf/templates/rz-conf-bananapi source poky/oe-init-build-env build

Apply a patch files

    $ patch -p1 < ../patch/0000-AI_SDK-settings.patch
    $ patch -p1 < ../patch/0001-tesseract.patch
    $ patch -p1 < ../patch/0002-openmp.patch

Decompress OSS files to build directory.

    $ 7z x oss_pkg_rzv_*.7z -o ai2n_yocto/build

Run the following command to build the yocto image, All necessary files listed below will be generated by the build command and they will be located in build/tmp/deploy/images/bananapi-ai2n directory

    $ MACHINE=bananapi-ai2n bitbake core-image-weston

Run the following command to build cross compiler installer, A necessary file listed below will be generated by the build command and the cross compiler installer will be located in build/tmp/deploy/sdk/poky-glibc-x86_64-core-image-weston-aarch64-bananapi-ai2n-toolchain-*.sh.

    $ MACHINE=bananapi-ai2n bitbake core-image-weston -c populate_sdk
